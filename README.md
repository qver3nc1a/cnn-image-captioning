# CNN Image Captioning
An experiment project investigating image captioning generation using learned visual representations.

## Goal
Build an image-captioning system:
image -> CNN visual encoder -> visual features -> text decoder -> generated caption

## Research interests
- CNN feature extraction
- learned visual representations
- image captioning
- text generation
- architectural modifications
- model evaluation

## Experiments (planned)
- CNN architecture
    - shallow
    - medium
    - deep
- Representations
    - single feature vector
    - spatial feature map
- Decoder architecture
    - RNN
    - Transformer

## Questions
- How does CNN depth affect image-captioning performance?
- How does the representation passed from the CNN to the text decoder affect caption generation?
- How does decoder architecture affect generated captions?
